# Scientific Calculator - Update Log

## Update Log: v1.0
* **Normal Scientific Calculator.**
* **v1.0 Baseline:** Initial single-file scientific calculator featuring full trigonometric/logarithmic functions, keyboard support, and core evaluation engine.

## 🚀 Update Log: v1.1
* **Audio Feedback:** Added sound effects for clicks and added `FahhSound` triggered when an error appears.
* **Layout Adjustment:** Swapped the positions of the decimal point (`.`) and zero (`0`) on the bottom row.
* **Bug Fixes:** Resolved browser audio decoding and loading issues.

## 🚀 Update Log: v1.2
* **New Feature:** Added sound effect / BGM (`MathsEditSound`) when the calculation result is Infinity/-Infinity.
* **Easter Egg:** Added custom `U.S. POLO` result trigger for a specific calculation sequence.
* **Performance & UI:** Fixed bugs and made it all device optimized for faster typing making it lag even less, close to zero, capped input segments at 60 digits, and added operator layout updates.
* **Bug Fixes:** Resolved additional bugs regarding `FahhSound` not working properly.

## 🚀 Update Log: v1.2.1
* **UI Enhancement:** Updated the navigation return mechanism to a dedicated interactive button layout.
* **Audio Integration:** Configured the return action button to seamlessly trigger Sound Effect prior to navigation.

## 🚀 Update Log: v1.2.2
* **Audio Feedback:** Configured number keys to play the click sound effect when pressed.
* **Input Limit:** Implemented sound suppression once the 60-digit input segment limit is reached.

## 🚀 Update Log: v1.2.3
* **Keyboard Shortcut:** Added `Ctrl + Backspace` shortcut mapped to `AC` functionality, complete with synced button animations and audio feedback.
* **Visual Audio Sync:** Synchronized both on-screen buttons and physical keyboard inputs to trigger red mechanical vibration feedback during active audio events.
* **Performance & Versatility:** Reverted max input segment length to 16 digits and optimized performance specifically for mobile devices.
* **Secret Content Updates:** Included custom visual results such as the U.S. Polo text branding and high-voltage electrical zap effects, while silently removing a previous secret calculation sequence.
